# はじめに

pbtはGo向けのプロパティベーステストライブラリです。
プロパティとは、ある形をしたすべての入力について成り立つべきテストのことです。
pbtは入力を生成し、失敗した入力を小さなケースへ縮小し、そのケースを保存して、次の `go test` の実行で再現します。
機能の範囲はErlangの[PropEr](https://proper-testing.github.io/)に合わせています。
分布を利用者が制御できる生成器、その制御を確かめる統計、モデルに対するステートフルテストと並行テスト、状態機械、標的型探索、存在性のプロパティです。

このガイドはpbt v0.2.0を対象にしています。
`go test` でテストを書いていることを前提にしています。
関数ごとの説明は[パッケージドキュメント](https://pkg.go.dev/go.ymotongpoo.com/pbt)にあります。
ここでは、部品どうしがどう組み合わさるか、どの場面でどれを使うかを説明します。

## インストール

```sh
go get go.ymotongpoo.com/pbt@v0.2.0
```

pbtはGo 1.25以降で動き、標準ライブラリ以外に依存しません。
`go.ymotongpoo.com/pbt` としてimportします。

## 最初のプロパティ

プロパティは `*pbt.T` を受け取る関数です。
生成器から値を取り出し、`*testing.T` と共通のメソッドで失敗を報告します。
それを `pbt.Check` が実行します。

<!-- snippet: intro_test.go#largest -->

このテストでは3つのことが起きています。
`pbt.SliceOfN(pbt.Int(), 1, -1)` は、要素が1つ以上で上限のないスライスの生成器です。
生成器は `pbt.Gen[V]` 型の値なので、変数に入れて使い回せます。
`Draw(t, "xs")` は、現在のテストケースの値を1つ作ります。
ラベルは、失敗の報告でその値を指す名前になります。
`pbt.Check(t, prop)` はプロパティを100回実行します。
サイズパラメーターは実行の間に1から42まで増えるので、最初のケースは小さく、後のケースほど大きくなります。
サイズは3章で説明します。

`*pbt.T` には `Errorf`、`Fatalf`、`Logf`、`Cleanup` など `*testing.T` の報告用メソッドがあるので、プロパティは普通のテストと同じように読めます。
プロパティの中で起きたパニックも失敗として扱われます。

## プロパティが失敗したとき

次の実装にはバグがあります。
最大値を0から始めているので、要素がすべて負のときに間違います。

<!-- snippet: intro_test.go#biggest -->

`pbt.Check(t, biggestProperty)` を実行すると、次の報告が出ます。

```text
[pbt] property failed after 12 passed checks and 16 shrink steps (size 13)
[pbt] xs (SliceOfN(Int(), 1, -1)) = []int{-1}
[pbt] error: biggest([-1]) = 0, want -1
[pbt] saved to testdata/pbt/TestBiggest/5a0c…; go test replays it until the file is deleted
[pbt] reproduce: go test -run 'TestBiggest' -pbt.seed=0x1
```

1行ずつ読んでみましょう。

1行目は、失敗までに通過したケースの数と、表示しているケースに至るまでの縮小のステップ数です。
失敗したケースはサイズ13で見つかりました。

次に、プロパティが取り出した値が、ラベル、生成器、値の順にすべて並びます。
最初に失敗したスライスには13個の要素がありました。
縮小器がそれを1個にまで減らし、その1個を最小の負の数にしました。
`[-1]` が、まだ失敗する最小の入力です。

`error:` の行は `Fatalf` に渡したメッセージです。
ログの行、パニック、`OnFail` のコールバックの出力もここに並びます。

このケースは `testdata/pbt` の下の、テスト名のディレクトリに保存されました。
次の `go test` は新しいケースを生成する前にこれを再実行するので、直すまでバグは見え続けます。
ファイルは削除しても、回帰テストとして残してもかまいません。
最後の行は、シードを含めて同じ実行を再現するコマンドです。

## このガイドの構成

各章は前の章の内容を前提にしています。
1章から4章は、生成器、データのサイズと分布、縮小、実行のオプションを扱います。
5章から7章は、モデルに対するステートフルテスト、並行実行、状態機械を扱います。
8章は標的型探索と存在性のプロパティ、9章は型から導く生成器です。
10章では、例題の移植、rapidからの移行ガイド、参照資料を案内します。
