# 例題: プロパティはどう思いつくのか

このディレクトリには、山口能迪『プロパティはどう思いつくのか　プロパティベーステスト発見ガイド』の例題を `go.ymotongpoo.com/pbt` で書いたGoのコードがあります。
この本の主題はライブラリの使い方ではなく、プロパティの見つけ方です。
各章は仕様から出発してプロパティを導き、そのプロパティが仕込んだバグを捕まえることを確かめます。

## 実行のしかた

`examples` ディレクトリでテストを実行します。

```sh
go test -race ./discovery/...
```

名前が `Mutant` で終わるテストは、仕込んだバグに対してプロパティを実行するもので、失敗するのが正しい結果です。
テスト全体を通る状態に保つため、これらのテストは環境変数 `PBT_MUTANTS` がなければスキップします。
`run_mutants.sh` は通常のテストを実行してから、変異のテストを1本ずつ実行し、通ってしまった変異を報告します。

```sh
./discovery/run_mutants.sh
```

1つの変異の報告を読むには、そのテストを直接実行します。

```sh
PBT_MUTANTS=1 go test -run '^TestRuneExactEmptyMutant$' ./discovery/ch02
```

スケジュールに依存するテストや、多数回の実行で検出率を計測するテストは、`PBT_FLAKY=1` や `PBT_MEASURE=1` がなければスキップします。
第16章の、レースディテクターでだけ失敗する変異は `-race` を付けたときにビルドされます。

コード中のコメントとメッセージは、本と同じく日本語です。
